# Command Reference

## Market

- `/market` — exchange overview
- `/market quote <ticker>` — company quote and fundamentals
- `/market top` — top companies by market cap

## Companies

- `/company create <name> <ticker>` — create a company
- `/company info <ticker>` — inspect company details

## Trading

- `/trade buy <ticker> <shares>` — buy shares
- `/trade sell <ticker> <shares>` — sell shares
- `/trade portfolio` — show current holdings

## Administration

The repository reserves `/marketadmin` for server operators. Planned actions include forced ticks, market pause/resume, delisting, news injection and treasury adjustments.
