# Game Loop

1. Players create companies or buy into existing ones.
2. Company activities add or remove treasury/revenue.
3. Trades create short-lived order pressure.
4. News modifies sentiment.
5. Every market tick recalculates share prices.
6. The server updates market boards and leaderboards.
7. Dividends may be distributed.
8. Ownership changes can trigger takeovers.

The market is intentionally reflexive: players react to a price, and their reaction influences the next price.
